# 🦎 Animated Reptile Following Cursor

An interactive Python animation where a green reptile smoothly follows your 
mouse cursor across the screen. Built with **Pygame**, this project 
demonstrates real-time animation, inverse kinematics, and vector math — 
all in a single file.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Pygame](https://img.shields.io/badge/Pygame-2.0%2B-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## 🎬 Features

- 🐍 **Segmented body** — 12 spine segments follow the head using inverse kinematics
- 🦵 **Animated legs** — Four legs swing naturally as the reptile moves
- 👀 **Tracking eyes** — Eyes always look toward the cursor
- 👅 **Flicking forked tongue** — Tongue periodically darts in and out
- 🎯 **Smooth cursor tracking** — Angle interpolation for natural turning
- 🌿 **Themed background** — Randomly placed grass tufts for atmosphere
- ⚡ **60 FPS gameplay** — Runs smoothly on any modern machine
